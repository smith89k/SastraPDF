# No ZIP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Split and Export as images save separate files into a chosen folder; JSZip leaves the app.

**Architecture:** main.js gets `pick-folder` (folder picker + name-clash question, returns final names);
index.html gets `saveMany`, used by `split` and `exportImages`, writing each file with `write-file` as it
is made. Spec: `docs/superpowers/specs/2026-10-15-no-zip-design.md`.

**Tech Stack:** Electron 44 dialogs, pdf-lib, pdf.js; Playwright (`playwright-core`, outside the project).

## Global Constraints
- No new libraries; remove JSZip everywhere. Keep pako (pdf-lib uses it).
- Tests stub `dialog.showOpenDialog` / `showMessageBox` / `showSaveDialog` in main; launch with
  `--user-data-dir=<scratch>` and without `ELECTRON_RUN_AS_NODE`.
- Test script: `<scratchpad>/t/nozip-test.js`.
